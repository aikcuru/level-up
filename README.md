# Level Up

Level Up — статический планировщик школьных задач, подготовки к ЕГЭ, олимпиадам, поступлению, курсам и личным делам.

Опубликованное приложение: [https://aikcuru.github.io/level-up/](https://aikcuru.github.io/level-up/)

## Возможности MVP

- создание профиля;
- направления задач и учебные предметы, включая дополнительные;
- создание, редактирование, выполнение и удаление задач;
- три уровня сложности с наградами 5, 20 и 50 XP;
- уровни пользователя и шкала прогресса;
- дедлайны, отображение просрочки и учёт переносов;
- фильтры по статусу, направлению и предмету;
- обзорный месячный календарь;
- адаптивный интерфейс для компьютера и телефона;
- хранение данных в `localStorage`.

## Технологии

- HTML;
- CSS;
- JavaScript;
- `localStorage`;
- GitHub Pages.

## Запуск локально

Команды выполняются в Windows PowerShell в папке:

```powershell
cd C:\Projects\level-up
```

Команда запуска:

```powershell
py -m http.server 8000
```

После запуска приложение доступно по адресу:

[http://localhost:8000/](http://localhost:8000/)

## Структура проекта

- `index.html` — семантическая разметка и основные блоки интерфейса.
- `style.css` — оформление, адаптивная компоновка и состояния элементов.
- `script.js` — логика задач, XP, фильтров, календаря и хранения данных.
- `concept.md` — концепция и границы MVP.
- `tz.md` — техническое задание и критерии приёмки.
- `plan.md` — последовательность разработки и журнал проверок.

## Хранение данных

Данные сохраняются только в браузере в `localStorage` под ключом `levelUpState`.

Данные, сохранённые для разных адресов приложения или на разных устройствах, не синхронизируются.

## Улучшения после MVP

Следующие возможности пока не реализованы:

- доступный просмотр задач, скрытых за «+ ещё N»;
- самостоятельный выбор цветов предметов календаря.

## Статус проекта

MVP завершён, проверен и опубликован.
